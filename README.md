# Linea Atelier Template

A premium architect agency landing page built with Next.js, Tailwind CSS v4, shadcn/ui, and Framer Motion. Content is centralized for fast customization, and the animations respect reduced-motion preferences.

## Stack

- Next.js App Router
- Tailwind CSS v4
- shadcn/ui components
- Framer Motion

## Quickstart

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000 to view the site.

## Customize Content

Edit the data file to change project names, services, and contact info:

- `data/site.ts`

Layout and section structure live in:

- `app/page.tsx`

## Images

Replace the sample images in:

- `public/images`

Keep the filenames the same or update the paths in `data/site.ts`.

## Notes

- Animations are powered by Framer Motion and reduced-motion safe.
- The UI uses shadcn/ui components in `components/ui`.
